## CDN 本地化完成（2025-08-12 下午）

### 改动内容
1. **static/vendor/** 新建目录，存放 4 个库（共约 7MB）：
   - `font-awesome/`（css/all.min.css + webfonts/ 4 个 woff2 + 4 个 ttf）
   - `highlight.js/styles/`（github.min.css、github-dark.min.css）
   - `mermaid/mermaid.min.js`（3.5MB 单文件）
   - `mathjax/tex-chtml-full.js` + `mathjax/fonts/`（23 个 MathJax_*.woff 字体）
2. **templates/base.html** — 5 处 CDN 引用全部改为 `{{ SITE.baseUrl }}/vendor/...`：
   - Font Awesome、highlight.js×2 主题、Mermaid、MathJax
3. **MathJax 关键坑**：原 `tex-mml-chtml.js`（动态加载器）换成 `tex-chtml-full.js`（单文件完整版，含全部 TeX 组件）；字体必须本地化，否则运行时仍从 jsdelivr 拉字体。配置从 `options.chtml`（无效位置）移到顶层 `chtml: { fontURL: '...' }`

### 验证结果
- 生成 HTML 0 个 CDN 引用；mermaid/mathjax JS 内部无运行时外部加载
- 全站 1448 个本地资源引用全部有效（含 CSS url() 字体）
- 本地服务器 9090 所有 vendor 资源 200
- 注意：Font Awesome css 中 woff2 在 ttf 前，浏览器优先用 woff2

- mermaid：jsdelivr mermaid@11
- mathjax：npm registry tarball（mathjax-3.2.2.tgz），拷贝 es5/tex-chtml-full.js + woff-v2 字体
